# Página de práctica HTML y CSS

Proyecto sin frameworks: estructura HTML semántica, estilos en una hoja CSS externa y JavaScript pequeño para validar el formulario y agregar registros a la tabla.

## Cómo abrirlo

1. Descomprime la carpeta del proyecto.
2. Abre `index.html` en un navegador o abre la carpeta en Visual Studio Code y ejecuta Live Server.
3. Para probar el formulario, introduce un nombre y un correo válidos y pulsa **aceptar**.

## Archivos

- `index.html`: estructura y contenido.
- `css/style.css`: colores, tamaños, distribución y estilos adaptables.
- `js/app.js`: comportamiento del formulario y navegación.
- `img/iceberg.jpg`: imagen panorámica extraída de la captura de referencia proporcionada en la conversación.
